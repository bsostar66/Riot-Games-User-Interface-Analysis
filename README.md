## 1. Opis projekta

Projekt obuhvaća analizu korisničkog sučelja web stranice tvrtke Riot Games. Cilj projekta bio je procijeniti kvalitetu dizajna i korisničkog iskustva te prepoznati njegove prednosti i nedostatke.

Analiza je usmjerena na vizualni dizajn, navigaciju, preglednost sadržaja, responzivnost i interaktivnost web stranice.

## 2. Korištene tehnologije

| Tehnologija | Opis |
|---|---|
| Figma | Izrada i prikaz dizajnerskog rješenja |

## 3. Analiza korisničkog sučelja

**Pozitivni aspekti:**
- Atraktivan vizualni dizajn i moderna tipografija.
- Jednostavna i intuitivna navigacija.
- Prilagodba različitim veličinama zaslona.
- Brzo učitavanje stranica.
- Pregledan i logično organiziran sadržaj.

**Negativni aspekti:**
- Nedostatak relevantnih informacija na naslovnoj stranici.
- Nedovoljna raznolikost sadržaja.
- Nedostatak interaktivnih elemenata.
- Nedostatak jednostavne navigacije prema pojedinim sekcijama naslovne stranice.

## 4. Projektna dokumentacija

Projektna dokumentacija sadrži detaljniji prikaz analize korisničkog sučelja i prepoznatih prednosti i nedostataka.
